# 이해관계자 카탈로그

이 문서는 [제품 랜딩](../03-product.md)의 기존 이해관계자 정의만 분리해 보여 준다. 운영 권한의 세부 경계는 [운영 권한 경계](02-operational-authority.md)를 함께 본다.

이 페이지는 새 stable ID를 만들지 않고, 제품 범위를 바꾸지 않는다. 현재 구현 범위는 정적 SPA이며, CMS는 Proposed 상태의 전환 후보일 뿐이다.

| ID | 이름 | 설명 |
|---|---|---|
| `STK-001` | Hy-Climb 동아리원 | 센터, 가격, 위치, 모임 장소를 빠르게 확인하는 주 사용자 |
| `STK-002` | 신규 방문자 | 동아리 정보를 처음 보고 센터 목록과 길찾기를 확인하는 외부 사용자 |
| `STK-003` | 동아리 운영진 | 현재는 정적 JSON과 이미지로 센터, 이벤트, 정기모임 정보를 관리하며, Proposed CMS 전환에서는 운영 콘텐츠 책임 경계를 갖는 사람 |
| `STK-004` | 정적 호스팅 환경 | Cloudflare Pages 같은 정적 호스팅과 SPA 라우팅을 제공하는 배포 표면 |
| `STK-005` | 네이버 지도 | 길찾기 URL을 처리하는 외부 서비스 |

## STK-003 경계

`STK-003`은 현재 구현에서 파일 기반 운영을 맡는다. 센터, 이벤트, 정기모임 정보는 정적 JSON과 이미지 변경으로 관리되며, 현재 public static SPA에는 로그인, RBAC, 관리자 화면, CMS 런타임이 없다.

Proposed CMS 전환이 승인되면 `STK-003`은 운영 콘텐츠 책임 경계를 가질 수 있다. 이 책임은 CMS 후보의 운영 콘텐츠 관리에 대한 것이며, public app 인증이나 공개 사용자 편집 권한을 뜻하지 않는다.

## 범위

이 페이지는 `STK-001`부터 `STK-005`까지의 이해관계자 카탈로그만 다룬다. `STK-006` 같은 새 ID를 만들지 않으며, CMS 구현, public-app authentication, RBAC, 관리자 화면은 이 문서 범위 밖이다.
